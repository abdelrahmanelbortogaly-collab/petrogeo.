# منصة PETROGEO الأكاديمية لعلوم الجيولوجيا وهندسة البترول 🛢️

منصة تعليمية متكاملة لطلاب كليات العلوم والهندسة، تشمل:
- نظام إدارة المحتوى والمحاضرات والسكاشن العملية والمعامل.
- بنك الأسئلة والامتحانات التفاعلية والتصحيح التلقائي.
- نظام الحماية المتقدم من تنزيل ملفات الـ PDF أو تصوير الشاشة مع علامات مائية ديناميكية.
- نظام الاشتراكات والدفع عبر InstaPay.
- لوحة تحكم الأدمن وإدارة فريق المشرفين (Co-Admins).
- ربط سحابي متقدم مع قاعدة بيانات Supabase.

## 🚀 التشغيل المحلي (Local Development):
```bash
npm install
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 📦 البناء للإنتاج (Production Build):
```bash
npm run build
```

## 🌐 دليل النشر الكامل:
يرجى قراءة ملف **`DEPLOYMENT_GUIDE.md`** لمعرفة خطوات النشر على:
- **Vercel** (موصى به لدعم الـ Serverless API بالكامل)
- **GitHub Pages** (عبر GitHub Actions التلقائي المرفق)
- **Surge** (`npx surge dist`)
